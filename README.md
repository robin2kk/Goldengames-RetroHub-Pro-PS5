# GoldenGames RetroHub Pro

A native PS5 retro gaming frontend by GoldenGames, with a 3D cover-flow interface and RetroArch integration.

## Features

- Horizontal 3D cover flow with game artwork.
- Automatic cover downloads and ROM scanning.
- Support for 19 configured systems, including PlayStation, Nintendo 64, and Sega Saturn.
- Synthesized menu sounds and controller navigation.
- Light-blue interface with white header and footer, console names, game titles, and emulator information.
- Hold L1 + R1 + touchpad to return from a game. The PS5 menu may appear briefly before RetroHub returns.

## Compatibility

Tested by the author on PS5 firmware **5.10**. Other firmware versions have not been tested by the author.

RetroArch must be installed and configured separately. The launcher uses the Homebrew Launcher/websrv integration; the required service must be enabled to launch games.

## Release status

The latest tested build is being prepared for publication. No installable release is available in this repository yet. Installation instructions and the matching source code will accompany the release.

ROMs, BIOS files, saved games, and personal configurations will not be included. Console BIOS files must be supplied by the user where required.
